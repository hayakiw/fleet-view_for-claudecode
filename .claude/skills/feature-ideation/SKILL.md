# 機能提案の進め方

## 1. 理解する
- 対象プロダクトが何のためのものか、誰が使うかをREADME・コードから把握する
- 既存の機能一覧を確認し、重複した提案をしない

## 2. 課題・不足を見つける
- 実際に使う場面を想像し、手間がかかる・分かりにくい・できないことを洗い出す
- コード中のTODO/FIXMEコメントや、機能の抜け漏れも手がかりにする

## 3. アイデアを出す
3〜5個程度、それぞれ以下をセットでまとめる:
- **誰の・どんな課題を解決するか**
- **機能の概要**（1〜2行）
- **実現しやすさの目安**（既存の仕組みで比較的簡単／それなりの設計が必要 等）

## 4. 優先度をつける
- 効果の大きさ・実現しやすさの観点で簡単に順位をつける

## 5. まとめて報告する
- コードは書かない・修正しない
- 簡潔に、次のアクションが分かる形でまとめる
