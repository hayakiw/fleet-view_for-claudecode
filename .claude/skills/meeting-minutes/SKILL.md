# 議事録作成の進め方

## 1. 理解する
- 渡されたメモ書き全体に目を通し、会議の目的・全体の流れを把握する
- 日時・参加者などメモに書かれている情報を確認する。書かれていなければ「不明」とする

## 2. 整理する
- メモの内容を「決定事項」「議論・意見」「未決事項・ToDo」に仕分ける
- 決定事項と、単なる意見・検討中の案を混同しない
- ToDoには、メモから分かる範囲で担当者・期限を添える。分からなければ空欄にする
  （憶測で埋めない）

## 3. 構成テンプレート
1. **日時・参加者**（メモに情報がなければ「不明」と明記）
2. **アジェンダ / 話した内容の要約**
3. **決定事項**
4. **未決事項・ToDo**（担当者・期限があれば併記）
5. **次回までの宿題**（該当する場合）

## 4. 書く
- 誰が読んでも同じ理解になるよう、曖昧な表現を避ける
- メモにない情報を推測で補わない

## 5. コミットする
- 議事録を保存したら、内容が分かるメッセージでローカルgitにコミットする
- 明示的に指示されない限り push はしない
