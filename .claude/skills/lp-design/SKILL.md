# LP作成の進め方

## 1. 理解する
- 誰に何を伝え、閲覧者にどんな行動（CTA: 申込・購入・問い合わせ等）をしてほしいかを明確にする
- ターゲット層・トーン（信頼感重視か、勢い重視か等）を確認する
- プロジェクト内に既存のブランド要素（ロゴ、配色、フォント、既存LP）があれば読み込んで踏襲する

## 2. 構成テンプレート例
1. **ファーストビュー**: キャッチコピー、サブコピー、主要CTAボタン
2. **課題提起 / 共感**: 対象読者が抱える課題
3. **解決策・特徴**: 提供する価値、3〜5個の特徴
4. **社会的証明**: 実績、利用者の声、ロゴ等（材料がなければ省略し、その旨を報告する）
5. **料金・プラン**（該当する場合）
6. **よくある質問**（該当する場合）
7. **最終CTA**: フッター直前に再度行動喚起

## 3. 作る
- HTML/CSSは自己完結（インラインstyleまたは1ファイル内の`<style>`）にする
- レスポンシブ必須。スマホ幅（375px程度）でも崩れないことを確認する
- CTAボタンは視認性を優先した配色・サイズにする
- 実データ・実績がない項目はダミーで埋めず、プレースホルダーである旨が分かるようにするか
  該当セクションを省略する

## 4. 確認する
- 主要CTAがファーストビューと最後の両方にあるか
- スマホ幅・PC幅の両方で崩れがないか

## 5. コミットする
- 完成したら、内容が分かるメッセージでローカルgitにコミットする
- 明示的に指示されない限り push はしない
