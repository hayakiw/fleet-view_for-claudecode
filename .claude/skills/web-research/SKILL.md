# Web調査・情報収集の進め方

## 1. 理解する
- 調査テーマ・目的（何を明らかにしたいか、誰がこの調査結果を使うか）を明確にする
- 曖昧な場合は無理に進めず、不明点を報告する

## 2. 情報収集する
- WebSearch/WebFetchでテーマに関する情報を集める。一次情報・信頼できる情報源を優先する
- プロジェクト内の既存ドキュメント・コードも関係があれば読み込む
- 集めた情報の出典（URL）を必ず記録しておく
- 情報源によって主張が食い違う場合は、両論併記するか信頼度の違いを明記する

## 3. 整理する
- 論点・トピックごとに整理する
- 事実（出典のある情報）と推測・意見を明確に区別する

## 4. 調査メモとして書く
以下の構成を基本とする（テーマに応じて増減してよい）:
1. **概要**: 調査テーマ、結論の要約
2. **論点ごとの詳細**: 見出し＋要点＋出典
3. **未解決・要確認事項**: 調査で分からなかったこと
4. **参考文献**: 出典一覧（URL）

## 5. コミットする
- 調査メモを保存したら、内容が分かるメッセージでローカルgitにコミットする
- 明示的に指示されない限り push はしない
