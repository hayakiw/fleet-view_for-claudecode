# 実装の進め方

## 1. 理解する
- 着手前に既存のコード規約・構成を確認する
- 指示が曖昧な場合は、無理に進めず不明点を報告する

## 2. 実装する
- 指示された範囲に留める。ついでのリファクタや大規模変更はしない
- 既存のパターンに合わせる（新しい依存関係やスタイルを勝手に持ち込まない）

## 3. 確認する
- 変更したコードの構文チェックを行う
- 既存のテストがあれば実行する
- 可能な範囲で実際に動かして確認する

## 4. コミットする
- 変更内容が明確にわかるメッセージでローカルgitにコミットする
- 明示的に指示されない限り push はしない
